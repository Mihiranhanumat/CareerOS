# Factuality & Zero-Hallucination Rules

1. **No Invented Facts**: Never fabricate employment history, projects, metrics, certifications, or skills.
2. **AI Changes are Proposals**: Informal natural-language updates and inferred repository technologies must remain in a `pending` proposal state until explicitly approved by the user.
3. **Evidence Requirement**: Every material bullet point generated in Resume Studio must trace back to supporting evidence IDs in the database.
4. **Hard Blocker Gate**: If a candidate fails a hard eligibility requirement (e.g., citizenship or relocation constraint), the match engine must cap the score and flag the blocker rather than allowing semantic similarity to override it.
