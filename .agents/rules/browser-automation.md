# Browser Automation & Human Checkpoint Rules

1. **Safety Compliance**: Never attempt to bypass CAPTCHAs, MFA/2FA, anti-bot mechanisms, rate limits, or access controls.
2. **Mandatory Human Checkpoints**: Always pause automation and prompt the user for:
   - Work authorization / visa sponsorship declarations
   - Legal, background, or disciplinary self-identification questions
   - Irreversible final submission confirmation
3. **No Duplicate Submissions**: Never submit a form twice due to network uncertainty.
4. **Source Policies**: If a platform (e.g. LinkedIn) prohibits automation, automatically switch to manual-assist mode with field pre-population.
